# Privacy policy: SV Number browser extension

Last updated: November 14, 2026

This policy covers the browser extension "SV Number: Receive SMS & Phone Numbers for Signups" (the extension). The extension works with your SV Number account and your API key. The privacy policy of the SV Number website is at https://sms-verification-number.com/en/privacy-policy/

## What the extension stores

The extension stores your SV Number API key in the local storage of your browser (chrome.storage). The same storage holds the extension settings, the phone numbers you buy through the extension, the SMS codes you receive and a cached list of services. This data stays in your browser. Apart from the API requests described below, the extension does not send it anywhere.

## Where the extension sends requests

The extension sends requests only to the SV Number API at sms-verification-number.com. A request contains your API key and the details of your action, such as the service, the country and the number you ordered. The extension does not contact any other server.

## What the extension reads on web pages

When you click the extension, it reads the domain name of the active tab, for example example.com, and uses it to suggest a matching service. It reads the domain only after your click. The domain is matched inside your browser and is not sent to us.

The extension inserts the phone number you bought and the SMS code you received into the form on the tab where you use it. To do this, it scans that page for the phone and code fields. It does not collect, store or send other content of the page. After you get a number, the extension can insert the code when the SMS arrives, as long as you stay on that page.

## What we do not do

The extension has no analytics and no tracking tools. We do not sell your data and we do not transfer it to third parties, except as required by law. We do not use it to assess creditworthiness or for lending.

## How to delete the data

Remove the extension: the browser then deletes its local storage. You can also replace the API key at any time in the extension settings.
